# Premortem

Premortem 是一个面向科研实验设计的本地 AI 助手：把模糊想法逐步收敛为可交给编码 agent 的实验方案，同时保留用户对流程、推断和持久记忆的最终控制权。

## Quick start

目标平台为 Windows、WSL 和 macOS。准备支持 Rust 2024 edition 的工具链，以及至少一个兼容的模型 API 密钥。

```sh
cargo run --bin serve -- . 7878
```

第一个参数是项目数据目录，也是本地文件工具默认可读的根目录；分析其他项目时，把 `.` 换成对应路径。

然后打开 [http://127.0.0.1:7878](http://127.0.0.1:7878)：

1. 在“配置”中为 `judge`、`answer`、`subagent` 三个角色选择 provider 和模型，并存入相应密钥。
2. 在输入框下方确认模型可读的项目目录；需要时可在“工具”中调整目录、联网和返回体量限制。
3. 回到“对话”开始描述要验证的想法或现有实验方案；若当前没有会话，再点击“新对话”。

也可以先通过环境变量提供密钥。

Windows PowerShell：

```powershell
$env:ANTHROPIC_API_KEY = "sk-..."
cargo run --bin serve -- . 7878
```

macOS / Linux / WSL：

```sh
export ANTHROPIC_API_KEY="sk-..."
cargo run --bin serve -- . 7878
```

服务只监听本机 `127.0.0.1`。HTML、CSS 和 JavaScript 已编进 Rust 二进制，不需要 Node 构建步骤。网页抓取也内置在 Rust 进程中：抓取开关、域名白名单和体量限制可在“配置 → 工具权限与上限”中调整。

## 主要应用场景与功能

- **从 idea 到实验 brief**：帮助澄清 claim、检查假设、补充对照、评估成本并在合适时收敛。
- **过往场景分流与蒸馏**：易于替换和插拔的失败经验和场景参考，每次turn正式回答前都会做一次场景分流，减少错误再犯的可能。
- **结构化显式工作记忆**：侧栏展示实验流程图、图外字段、待落定问题和搁置项。模型通过动作工具即时更新，用户编辑也即时生效；同一轮内用户刚改过的位置不会被模型的旧快照覆盖。
- **探索/行动两种模式**：探索模式允许展开和开放式追问；行动模式偏向方法、超参和实现细节，并关闭讲解类场景。阶段切换始终由用户决定。
- **安全、可恢复的工具与会话**：模型没有裸 shell 和任意文件写入能力；本地读取受目录与文件名策略限制，联网受协议、域名和体量限制。会话以 SQLite 事件时间线保存，支持恢复、崩溃修补和从历史 turn 分支。
- **用户确认后的长期记忆**：项目概述、偏好、知识状态、场景、prompt 和案例保存在 `memory/`。一键蒸馏只生成草稿，用户逐节确认后才写回。


运行数据默认写在启动命令指定的目录：

| 路径 | 内容 |
| --- | --- |
| `config.json` | provider、模型角色和工具策略；旧版联网后端字段仍兼容读取但不再生效 |
| `secrets.json` | API 密钥；由界面写入时会自动加入 `.gitignore` |
| `premortem.db` | 会话、事件时间线与 checkpoint |
| `memory/` | 项目记忆、场景、prompt、案例和蒸馏草稿 |
| `workspace/` | 网页抓取等工具产生的临时材料 |
