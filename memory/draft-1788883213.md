## knowledge.md

# 知识与经验评估
你需要总结用户在对话中提到的领域中体现出的知识情况便于之后合作。

每条形如：`领域 / 具体点 — 掌握程度 — 依据`。掌握程度用三档：
**有储备**（可以直接问他）、**没储备**（先讲通机制再把判断交回）、**不清楚**（先问清楚这一点本身）。

- 例：持续学习 / BWT 与 forgetting measure — 不清楚 — 尚未在对话中出现
