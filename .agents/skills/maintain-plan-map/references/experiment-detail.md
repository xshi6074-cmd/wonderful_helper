# 实验细节规则

在设计或更新实验框架、模型接口、数据协议、消融和评测时读取本文件。只展开会改变当前判断或执行结果的细节，把它们接回相应 part；不要机械铺开整个清单。

## 从待支持的判断逆推

先明确要检验的判断及适用范围，再确定能支持／否定／暂不可判断的观测。逆推评测口径、对照、训练、结构、数据和工程条件；最后正向走一遍实际数据、梯度和状态路径。

为每个关键设计记录：

- 想改变什么行为，依赖哪些前提。
- 现有材料为何支持把它列为候选；材料与本任务条件有何差别。
- 哪个低成本观察能够区分它与替代解释。
- 不同结果分别保留、修改或终止哪条分支。

先检验高影响假设及路径是否能跑通，再安排细节搜索。用“对哪个决定有影响”给灵感排优先级；暂时无影响的想法挂到所属节点，写重启条件，不自动扩张实验队列。

## 数据 part

图中明确从原始数据到训练、验证和持出评测样本的变换及分支。记录相关的：

- 样本／预测单位、目标、时间网格、输入历史与预测范围、单位、缺失及异常的含义。
- 每种信息的实际可用时刻，训练与推理能看到什么；“数据的时间戳在过去”不一定意味着当时可获得。
- 精筛规则与依据、保留／排除计数、来源冲突、重复、数据版本。检查筛选是否用未来目标信息改变了任务人群，别把过滤后的容易样本当完整任务。
- 划分单位、时间或实体边界、窗口重叠及泄漏路径；必要时确定边界隔离范围。别把“时间划分”四个字当协议。
- 缺失填补、标准化、特征选择、分解与统计在哪个集合拟合，随后如何作用于验证／评测；未来协变量使用发布时可获得的预测还是事后实测。
- 插值／填补是否进入目标、loss、mask 或主评测；训练与评测样本口径是否一致。
- 分季节、风况、提前量或其他相关组的样本覆盖与不确定性。精筛提高可信度和减小样本量可能同时发生，按目标取舍。

数据规则变化时，把数据版本、对照可比性、原有结果与结论一起复查，不把不同批次直接混为同一排行榜。

## 结构、训练与状态 part

让展开图呈现实际模块、接口、监督和更新路径，而不只是模型名称。

- 写出关键输入输出的形状、每个轴的语义、时间／实体对齐、归一化与消费者。
- 写出共享与隔离参数、可训练／冻结范围、梯度路径，以及会改变学习含义的 `detach`／`no_grad`。
- 明确 loss 的对象、单位、归约轴、权重与 mask 分母；权重从何确定，改变什么目标。优化目标改变就复查与主评测及实际交付的关系。
- 明确每批／每步／每阶段的状态更新、统计拟合、缓存、teacher 或快照，以及使用更新前还是更新后的状态。
- 保留解释结果必需的训练预算、早停依据、随机种子、选择协议、配置与代码版本；没有实测时只给有依据的成本估计或待测项。
- 仅在相关时展开设备、dtype、batch、DDP 同步、恢复一致性，不用无关工程惯例填满图。

模型复杂度、更多信息、不同训练预算和不同目标都可能影响表现。通过对照区分这些因素，避免把未充分训练误判成结构上限。

## 消融 part 与并行边界

按 part 逐项设计能影响决定的消融，再针对有具体依据的交互项安排组合；不要做没有问题意识的全排列。

每个实验 `E_...` 至少记录：

| 字段 | 要回答的问题 |
| --- | --- |
| 问题／假设 | 这次比较将改变哪个决定，想排除哪个解释？ |
| 基线 → 变体 | 精确只改变什么，其他可能影响结果的条件固定什么？ |
| 数据与协议 | 使用哪个数据版本、划分、mask、选择与评测范围？ |
| 预算与随机性 | 用什么预算、选择方式与复测，如何处理噪声和调参次数差异？ |
| 观测与判据 | 比较哪项主指标和相关诊断，何时支持／否定／暂不可判断？ |
| 去向与证据 | 结果怎样改变图；实际运行 ID、配置、日志或产物在哪里？ |

“逐项”用于隔离关键变量；存在具体交互假设时，用小型因子实验或组合对照补充。移除模块后参数量、输入、训练预算或下游接口一起变化时，写出剩余混杂，不能宣称完全隔离。

在图中把可比的实验臂接到同一评测节点，标明：

- **可以并行**：独立实验、协议已固定、各自结果不会决定另一臂的设置、资源允许且已获执行授权。
- **需要串行**：上游数据审计、指标／基线冻结、候选筛选或前一结果决定后续设置。依赖未解除就画条件边，不为了并行先偷定。

画出预算／停止节点；大规模搜索只有在确实服务某个决定且获授权时才进入计划。图里的“并行”是逻辑安排，不是多代理或算力使用授权。

## 有效性标准与交付

在看到变体结果前确定效果判据，或明确 `Q_EFFECT` 等待确定。可以依据任务价值、误差容忍度、基线噪声或成本收益提出阈值候选；没有依据时不要编一个百分比。

区分三层结论：

1. **实现检查通过**：接口、mask、梯度、时间约束等相关行为得到实际检查。
2. **该协议下有收益**：在固定可比条件下，主指标、噪声／区间、关键分组与代价支持改善。报告准确范围与反例。
3. **机制解释得到支持**：还有针对替代解释的实验支持；更好的一次结果不自动证明机制。

样本多、指标下降或曲线看起来更尖都不是单独的有效性证明。诊断曲线帮助解释，最终判据要回到目标；未定、互相矛盾或覆盖不足时保留“暂不可判断”。

对配置选择与最终评测区分用途，避免反复查看持出结果后继续优化而仍称其为独立检验；若目标本来就是探索性分析，注明这一范围。

将交付也画入路径，明确相关的输出列、单位、时间范围、文件／报告格式、复现入口、必要证据及对齐时点。未给截止时间就标未决，不发明日期或自动设置提醒。每轮把已完成、正在等待、下次要验收的产物接到对应节点。
