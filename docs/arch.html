01记忆两层：文件就是界面

持久层不是一个不透明的存档，它是一组用户可以直接打开来改的文件。 这条约束决定了格式选择：叙述用 Markdown，结构化的场景目录用 TOML。

02上下文：灌全量，接近上限才折叠

只送最近 K 轮不现实 —— 用户会引用三十轮之前定下的东西。上一版那个滑动窗口删了。 

ContextLimit { max_prompt_tokens, trigger_at: 0.8, keep_recent_turns }
留两成余量的理由：折叠本身要一次模型调用，而这一轮的回答还没生成。
压到 100% 才动手，这一轮就直接超限失败了。
